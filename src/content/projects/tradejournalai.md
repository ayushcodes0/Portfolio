## Overview

Most traders know they *should* keep a journal, but spreadsheets make it tedious and hard to learn from. TradeJournalAI turns a trade log into a performance dashboard: every trade is recorded once, and the platform does the analysis.

I built it as a freelance full-stack developer, owning the product from the database to the dashboard.

## What I built

- **Trade logging** with automated PnL calculations, so traders never compute results by hand.
- **Interactive dashboards.** Charts and graphs (Chart.js) that visualize trading performance.
- **AI-driven insights** that surface patterns in a trader's history to support smarter decisions.
- **Subscriptions and payments.** Subscription management integrated with secure payment processing.
- **Authentication** using JWT-based auth to keep every trader's data private.

## Stack

React and TypeScript on the frontend with Tailwind CSS for styling; Node.js and Express.js for the API; MongoDB for storage.
